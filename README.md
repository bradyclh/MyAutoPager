# MyAutoPager

自動無縫翻頁 Tampermonkey 腳本 — 將下一頁內容無縫載入至網頁底部，無需手動點擊下一頁。

基於 [X.I.U 的 AutoPager](https://github.com/XIU2/UserScript) 重寫，移除外部 CDN 依賴，改為純本地規則管理。

## 功能特色

- **3 種翻頁模式** — XHR 靜態加載、按鈕自動點擊、iframe 提取
- **規則驅動** — 內建 ~16 條規則，支援自定義 JSON 規則覆蓋/擴充
- **純本地管理** — 無外部 CDN、無遠端規則更新、無 @connect 依賴
- **頁碼按鈕** — 左下角浮動頁碼，點擊暫停翻頁，右鍵回到頂部
- **自動捲頁** — 在頁碼按鈕上快速點兩下開始平滑自動捲動，再點兩下停止
- **SPA 支援** — 自動偵測 URL 變化，重新匹配規則

## 自動捲頁

在**頁面任意處快速點兩下**開始自動捲動，再點兩下停止。捲動中左側頁碼按鈕會轉為綠色。

手動滾輪或拖動頁面**不會**中斷自動捲動——拖到想看的位置後，捲動會從新位置繼續。

捲到頁底時會自然接續無縫翻頁，等於免手連續閱讀。下一頁還在載入時會原地等候（新內容一到就繼續往下捲）；若位置與內容都停滯超過 30 秒——例如已讀到全書結尾——就自動停止，不會讓捲動一直空轉。

| 操作 | 效果 |
|------|------|
| 頁面任意處快速點兩下 | 開始／停止**自動捲動** |
| Esc | 停止自動捲動 |
| 單擊頁碼按鈕 | 暫停／恢復**翻頁**（與自動捲動獨立，捲動不受影響） |
| 快速點兩下頁碼按鈕 | 同樣可開始／停止自動捲動 |
| 桌面版菜單「自動捲頁速度」 | 設定速度（10–200 px/秒，預設 40） |
| iPhone 版：捲動中在按鈕上垂直滑動 | 上滑加速、下滑減速（每階 10 px/秒） |

速度會記住，下次沿用。

雙擊手勢會避開按鈕、輸入框與**仍可點擊**的連結，也不會在選字時搶手勢，所以正常點連結與選取文字都不受影響。手勢認定後會把這一擊的後續事件吞掉，所以點兩下不會順手把底下的廣告一起點下去。為了讓雙擊不同時觸發觸控裝置的原生「雙擊放大」，腳本會對頁面設定 `touch-action: manipulation`（pinch 縮放不受影響）。

## 廣告彈窗攔截（iPhone 版）

小說站常靠「點畫面任何一處就開新分頁」賺廣告費，這也會讓雙擊手勢變得不能用。iPhone 版在 `@run-at document-start` 階段就佈好防線：

| 層 | 擋什麼 |
|---|---|
| `window.open` | 鎖成不可寫、不可重設。**必須早於頁面腳本**，否則廣告載入器早就把原始參考存起來了。腳本本身跑在 `@inject-into content` 的隔離世界，在那裡覆寫頁面看不到，所以這個鎖是塞成 `<script>` 到**頁面世界**執行的；同源 iframe 在插入 DOM 的當下與取用 `contentWindow` 時一併鎖上 |
| iframe | 跨域 iframe 補上不含 `allow-popups` 的 `sandbox`；同源 iframe（`contentWindow.open` 繞過手法）直接鎖掉它的 `open` |
| 程式化點擊 | 攔截 `a.click()`——錨點還沒進 DOM 時事件傳不到 `document`，點擊守衛攔不到 |
| 點擊守衛 | `javascript:` 與跨域 `_blank` 連結、可疑全頁覆蓋層、跨域 form 提交 |
| DOM 觀察器 | 廣告是**非同步注入**的，啟動時掃一次不夠；後來才插進來的廣告同樣被拆彈。正文以外只針對錨點與 class/id 像廣告的容器，站方自己的 inline `onclick`（字級、夜間模式）不受影響 |

站內的 `_blank` 連結不會被弄死，只是改成同分頁開啟；但正文範圍內的 `_blank` 一律擋掉，因為正文裡沒有任何正當理由開新分頁。

啟動提示會標明「頁面守衛 OK」或「頁面守衛被擋（CSP）」：網站若用 CSP 擋掉內嵌 script，`window.open` 這一層就上不去，只剩 DOM 層攔截。每次攔截到彈窗也會在畫面上顯示次數，方便分辨「有擋、但另有漏網之魚」和「根本沒在擋」。

防護不受「停用本站」影響——使用者關掉的是自動翻頁，不是廣告防護。

## 安裝

1. 安裝 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Brave / Firefox / Edge）
2. 點擊 [MyAutoPager.user.js](../../raw/main/MyAutoPager.user.js) 安裝腳本
3. 完成，瀏覽支援的網站時會自動翻頁

## 自定義規則

透過 Tampermonkey 菜單 → **「自定義翻頁規則」** 開啟 JSON 編輯器。

### 規則格式

```json
{
    "規則名稱": {
        "host": "domain.com",
        "url": "/正則表達式/",
        "pager": {
            "type": 1,
            "nextL": "下一頁連結的 CSS/XPath 選擇器",
            "pageE": "要提取的內容元素",
            "replaceE": "要替換的導航元素",
            "scrollD": 2000
        }
    }
}
```

### 翻頁模式

| type | 說明 | 使用場景 |
|------|------|---------|
| 1 | XHR 靜態加載（預設） | 大部分網站 |
| 2 | 自動點擊按鈕 | 有「載入更多」按鈕的網站 |
| 6 | iframe 提取 | 重度客戶端渲染的網站 |

### 規則欄位

| 欄位 | 說明 |
|------|------|
| `host` | 域名匹配：字串精確匹配、陣列多值、`"/regex/"` 正則 |
| `url` | URL 路徑匹配（可選）：`"/regex/"` 或 JavaScript 函數字串 |
| `nextL` | 下一頁連結定位：CSS 選擇器、XPath、`js;程式碼` |
| `pageE` | 要提取的內容元素選擇器 |
| `insertP` | 插入位置 `["selector", 1-6]`，預設為 pageE 最後一個元素之後 |
| `replaceE` | 要替換的元素（通常是頁碼導航） |
| `scrollD` | 觸發距離（px），預設 2000 |
| `scrollE` | 基準元素選擇器（改用距元素距離觸發） |
| `style` | 注入的 CSS（無 `{}` 時自動加 `display:none!important`） |
| `history` | 是否更新瀏覽器歷史記錄 |
| `retry` | 失敗後重試延遲（ms） |

### 鉤子函數

```json
{
    "function": {
        "bF": "插入前執行的程式碼（可修改 pageE）",
        "aF": "插入後執行的程式碼"
    }
}
```

### 繼承內建規則

自定義規則名稱與內建規則同名時，加 `"inherits": true` 可深度合併而非完全覆蓋：

```json
{
    "google": {
        "inherits": true,
        "pager": {
            "scrollD": 5000
        }
    }
}
```

## 菜單功能

| 功能 | 說明 |

## 與原版差異

| 項目 | 原版 AutoPager | MyAutoPager |
|------|---------------|-------------|
| 翻頁模式 | 6 種 | 3 種 |
| 規則來源 | 內建 + CDN 外置 + 自定義 | 內建 + 自定義 |
| 外部依賴 | 30+ CDN/代理域名 | 無 |
| 內建規則 | 200+ 條 | ~16 條 |
| 程式碼量 | ~3000 行 | ~1670 行 |
